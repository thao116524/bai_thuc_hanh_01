# Bài 2: Kiểm tra số nguyên tố

- Nhập một số nguyên dương n từ bàn phím.
- Kiểm tra điều kiện:
  + Nếu n < 2 thì không phải số nguyên tố.
  + Nếu n >= 2, đếm số ước số của n từ 1 đến n.
- Nếu số ước đúng bằng 2 (chỉ chia hết cho 1 và chính nó) thì đó là số nguyên tố, ngược lại không phải.
- In kết quả ra màn hình.
